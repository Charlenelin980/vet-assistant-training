模組一何時需要拍 X 光

X 光是住院部最常見的影像診斷工具。助理需要知道哪些臨床狀況必須拍攝，哪些需要先告知醫師評估，才能在第一時間協助醫師做出決定。

助理的職責 助理不可自行決定是否拍攝 X 光，所有 X 光拍攝均需醫師開立醫囑或口頭指示後方可執行。以下內容是協助你快速「辨識臨床症狀、第一時間通報醫師」的參考依據，不是自行判斷的標準。
🔴 需立即告知值班醫師的狀況

以下情況可能需要緊急拍攝 X 光，請在第一時間通報主治或值班醫師，不可拖延。

臨床症狀懷疑問題常拍部位注意事項
動物很喘、呼吸急促、張嘴呼吸胸腔積液、氣胸、肺水腫、心臟擴大、橫膈膜疝氣胸腔⚠️ 嚴重喘的動物需先詢問醫師，是否適合擺位（VD 可能加重呼吸困難）
超過 24 小時沒有排尿 / 尿量極少尿道阻塞、膀胱過度充盈、腎臟問題腹腔公貓尤其高風險，需緊急評估
腹部明顯膨大、緊繃腹腔積液、腸道阻塞、脾臟腫塊、子宮蓄膿腹腔若極度緊張可能先照 Lat，VD 視醫師指示
嘔吐不止、超過數次且吐出異物異物梗塞、腸道阻塞腹腔有時需加拍胸腔確認有無吸入性肺炎
超過 48 小時沒有排便 / 裡急後重便祕、巨大結腸、骨盆腔阻塞腹腔確認最後排便時間，一併告知醫師
跌倒、車禍、高處墜落後骨折、氣胸、內出血、橫膈膜撕裂胸腔 ＋ 腹腔（視醫師）外傷動物注意搬運，避免加重傷勢
咳嗽持續多日、運動不耐受心臟疾病、氣管塌陷、肺炎胸腔需記錄咳嗽頻率與聲音特徵
後肢無力 / 癱瘓椎間盤突出、脊椎骨折、腫瘤壓迫脊椎（由醫師指示特定節段）搬運時全程保持脊椎水平
⚠️
優先
通報
動物有呼吸困難時，請先讓動物保持舒適姿勢、給氧（若醫師指示），再告知醫師。切勿急著壓制擺位，嚴重喘的動物在 VD 臥姿下可能快速惡化。
🟡 需詢問醫師後執行的狀況

以下狀況同樣需要拍攝 X 光，但緊急程度較低，請先告知醫師並等待醫囑。

臨床症狀懷疑問題常拍部位
食慾不振超過 2 天腹腔臟器異常、異物腹腔
跛行、單肢不敢踩地骨折、脫臼、關節炎患肢（醫師指定部位）
術後常規追蹤確認恢復狀況、植入物位置視手術部位
懷孕確認 / 幼仔數量評估懷孕週數、胎兒骨骼發育腹腔
腫瘤分期術前評估肺部轉移、腹腔腫塊胸腔 ＋ 腹腔
常見症狀快速判斷
沒有排尿
立即告知醫師，記錄最後排尿時間、尿量、動物是否有蹲廁所姿勢但沒有尿出來。多半需要拍腹腔 X 光。
動物很喘
馬上通報醫師，給予安靜環境，不可強制壓制。等醫師評估後決定是否需要拍胸腔 X 光，以及採用哪種擺位。
便祕 / 不排便
告知醫師，記錄最後排便時間。醫師可能會安排腹腔 X 光確認糞便積量與結腸狀況。
嘔吐多次
記錄嘔吐次數、內容物（食物 / 液體 / 血液 / 異物），告知醫師。可能需要腹腔 X 光。
腹部膨大
告知醫師，觀察動物是否有疼痛反應。腹腔積液動物通常需要緊急處置。
模組二拍攝前準備

每次拍攝前確認人員、設備、動物狀態，可以減少重拍次數，也能保護工作人員安全。

人員配置原則
  • 至少需要 1 位操作人員（負責按曝光鍵）＋ 1 位壓制人員（固定動物）。
  • 壓制人員必須穿著鉛衣、戴鉛手套，不可以裸手在照射範圍內。
  • 懷孕員工不可進入拍攝室，不可接觸散射輻射。
  • 非必要人員全部退出拍攝室，關上門後再曝光。
⚠️
輻射
安全
任何人不可讓自己的手、腳或身體其他部位進入 X 光主射束範圍。鉛衣只能阻擋散射線，無法完全阻擋主射束的直接照射。
設備確認清單
🔲 鉛衣（操作 / 壓制人員各一） 🔲 鉛手套 🔲 鉛圍領（選用） 🔲 X 光版（DR panel / 片匣） 🔲 沙袋 / 固定帶 🔲 泡棉楔形墊 🔲 標記貼（L / R 分辨左右） 🔲 確認機器已預熱
拍攝前動物評估
評估項目如何確認異常時處置
呼吸狀態觀察呼吸頻率與型態，是否有張嘴呼吸立即告知醫師，不可強制壓制
意識狀態動物是否清醒、對刺激有無反應意識差的動物需醫師評估後再決定是否需要鎮靜
是否需要鎮靜由醫師判斷，助理不可自行決定通知醫師評估，備好鎮靜藥材
體重確認已記錄今日體重體重影響曝光參數設定
拍攝步驟通則
1
醫師開立醫囑
確認拍攝部位（胸腔 / 腹腔 / 四肢）、拍攝方位（Lat / VD / DV）、是否需要鎮靜。
2
備妥防護裝備，確認人員就位
壓制人員穿好鉛衣與鉛手套。無關人員離開房間。
3
擺位（依部位操作，詳見模組三、四）
放置 X 光板於動物正確位置下方，確認標記（L/R）方向正確。
4
調整光束範圍（collimation）
調整光束準直器，使照射範圍剛好涵蓋目標部位，縮小射野可減少輻射劑量與散射線。
5
確認動物靜止後曝光
告知壓制人員「要照了」，確認動物靜止不動，再按下曝光鍵。
6
確認影像品質
在電腦或 DR 面板確認影像清晰、沒有晃動、目標部位完整涵蓋，若需重拍先告知醫師。
7
安置動物，整理設備
將動物放回舒適位置，鉛衣掛好（勿折疊），清潔 X 光板表面。
常見拍攝位置術語
縮寫全名中文說明
Lat（RL）Right Lateral右側臥側照動物右側朝下臥，X 光由左側進入
Lat（LL）Left Lateral左側臥側照動物左側朝下臥，X 光由右側進入（心臟評估常用）
VDVentrodorsal腹背位動物仰躺，X 光由腹側（肚子）射向背側（背部）
DVDorsoventral背腹位動物趴著，X 光由背側射向腹側（喘的動物較舒適）
💡
小技巧
胸腔側照建議在吸氣末曝光（肺部充氣最大），腹腔側照則在呼氣末或自然呼吸時曝光。等動物呼吸平穩後再按快門，可減少影像模糊。
模組三胸腔擺位

胸腔 X 光主要用於評估肺臟、心臟、縱膈腔、橫膈膜與胸腔積液。標準胸腔系列通常包含側照（Lat）與VD 或 DV，由醫師決定拍哪幾個方向。

胸腔側照（Lateral）
右側臥 RL Lat
常用於：一般胸腔評估
動物位置：右側朝下臥
X 光板置於動物右側（朝下側）下方
左側臥 LL Lat
常用於：心臟評估（心臟貼近板面影像較清晰）
動物位置：左側朝下臥
X 光板置於動物左側（朝下側）下方
胸腔側照（Lateral）操作步驟
1
確認側別，放置 X 光板
將 X 光板水平置於拍攝台上。依醫師指示決定左側臥或右側臥。
2
讓動物側臥，前後肢拉直
輕柔地讓動物側臥於板上。將前肢向前方拉直，避免肱骨壓住前胸肺野；後肢向後方拉直，避免壓住後半部胸腔。
3
脊椎與胸骨保持水平
確認動物身體沒有旋轉，脊椎與胸骨在同一水平面。可用泡棉楔形墊墊在胸骨下方輔助。
判斷標準：兩側肋骨弧度重疊（不是一大一小），代表沒有旋轉。
4
確認照射範圍
光束範圍需涵蓋：前方到胸骨入口（第一肋骨前），後方到橫膈膜後緣（含最後肋骨），上下到脊椎與胸骨。
5
吸氣末曝光
觀察動物呼吸，在胸腔最大時（吸氣末）曝光，肺野面積最大，診斷效果最好。
ℹ️
擺位
判斷
側照品質判斷：肋骨要重疊（表示沒有旋轉），前肢不遮蓋肺野，橫膈膜要完整可見。若影像中兩側肋骨明顯錯位，代表動物有旋轉，可能需要重拍。
胸腔 VD 位（Ventrodorsal）

動物仰躺，背部朝下，X 光由腹側（肚子）射向背側（背部）。可對稱評估兩肺葉及心臟輪廓。

1
讓動物仰躺，脊椎在正中央
輕柔將動物翻仰躺。可用 V 型槽或兩個沙袋夾在兩側協助固定，確保脊椎正直、不歪向任何一側。
2
前肢向前方拉開
兩前肢向頭部方向拉直，使肱骨不壓住前葉肺野。可用沙袋或膠帶輕固定。
3
後肢自然放置或向後拉
後肢輕向後方伸直，避免壓住後葉與橫膈膜。
4
確認對稱性
從正上方看，確認胸骨在兩側肋骨中間。左右肋骨弧度對稱，代表動物沒有旋轉。
5
確認照射範圍後曝光
前方到第一肋骨，後方含完整橫膈膜，左右涵蓋肋骨外側緣。
⚠️
呼吸
困難
呼吸困難的動物不建議強迫 VD 擺位。仰躺姿勢會使腹腔臟器壓迫肺部，加重呼吸困難。此類動物請告知醫師，醫師可能改以 DV（趴臥） 方式拍攝，或先以側照取代。
胸腔 DV 位（Dorsoventral）

動物趴著，胸骨貼地，X 光由背部（背側）射向腹部（腹側）。適合呼吸困難、無法耐受仰躺的動物。

1
讓動物趴臥，胸骨接觸板面
動物自然趴下，胸骨貼於板上，讓動物保持舒適。
2
確認頭部自然前伸，頸部不扭曲
過度彎曲頸部可能影響氣道，讓動物頭部保持自然伸展。
3
X 光球管在動物正上方
確認球管與動物背部中線垂直，照射範圍同 VD 位。
胸腔擺位快速比較
方位動物姿勢優點缺點 / 限制
Lat（側照）側臥評估心臟大小、肺葉分布、橫膈膜左右肺葉重疊，無法個別評估
VD仰躺左右肺葉分開，心臟輪廓對稱清楚呼吸困難動物禁用
DV趴臥動物較舒適，呼吸困難時首選心臟形狀與 VD 略有差異
模組四腹腔擺位

腹腔 X 光用於評估肝臟、脾臟、腎臟、膀胱、胃腸道、子宮等臟器。標準系列為側照（Lat）加VD。

腹腔側照（Lateral）

動物側臥，與胸腔側照擺法相似，但照射範圍後移至整個腹部。

1
動物右側臥（通常）
依醫師指示決定側別。右側臥最常見，可使幽門（胃出口）靠近板面而充氣，方便評估。
2
前後肢拉直，脊椎與胸骨水平
同胸腔側照，前肢向前、後肢向後拉直。確認腰椎與腹部沒有旋轉（判斷方式：兩側腰椎橫突對稱重疊）。
3
確認照射範圍
前方涵蓋橫膈膜（含最後肋骨），後方到恥骨後緣（含整個膀胱），上下到脊椎背側與腹壁腹側。
4
呼氣末或平靜呼吸時曝光
腹腔不需要等吸氣，平靜呼吸或呼氣末曝光即可。
💡
小技巧
腹腔側照時，確認膀胱有完整包含在照射範圍內，尤其懷疑泌尿系統問題時更重要。恥骨附近的膀胱很容易被切掉，須特別注意。
腹腔 VD 位（Ventrodorsal）

動物仰躺，背部朝下，可對稱評估兩側腎臟、膀胱輪廓、腸道分布。

1
動物仰躺，脊椎置中
用 V 型槽或沙袋夾住兩側協助固定，確保脊椎不歪斜。
2
後肢向後方伸展
雙後肢向後方輕拉伸直，可以用沙袋或膠帶固定腳踝部位，讓腹腔下腹部完整顯露。
3
前肢向前方拉開
兩前肢向前方拉直，避免前肢重疊在腹腔前半部。
4
確認對稱性
從正上方看，腸骨翼（骨盆翼）應對稱，代表動物沒有旋轉。
5
確認照射範圍後曝光
前方含橫膈膜，後方到恥骨後緣，左右涵蓋腹壁外側。
腹腔擺位快速比較
方位動物姿勢主要評估注意事項
Lat（側照）側臥胃腸道氣體分布、腸道梗塞、腹腔整體確認膀胱完整涵蓋
VD仰躺兩側腎臟對稱性、膀胱、骨盆腔後肢拉直才能完整顯示下腹腔

便祕 / 巨大結腸腹腔 Lat ＋ VD評估糞便積量與結腸擴張程度

ℹ️
貓咪
提醒
貓咪常見的尿道阻塞多為公貓，症狀是頻繁蹲廁所但無尿、外陰部舔舐、嗚叫、嗜睡。懷疑時立即告知醫師，拍腹腔 X 光可看膀胱大小，協助決定是否緊急導尿。
模組五輻射安全

X 光輻射對人體有潛在傷害，醫院規定所有工作人員必須嚴格遵守防護原則，確保自身與同事的安全。

⚠️ 輻射防護三原則：時間 · 距離 · 屏蔽 縮短暴露時間、增加與射源距離、使用適當屏蔽（鉛衣）。三者缺一不可。
個人防護裝備（PPE）
裝備使用時機注意事項
鉛衣所有進入拍攝室且無法離開的人員穿前確認無破損，使用後掛好勿折疊（折疊會損壞鉛層）
鉛手套手部需靠近動物固定時手絕不可進入主射束範圍
鉛圍領需要保護甲狀腺時（選用）甲狀腺對輻射特別敏感
輻射劑量計（TLD）常規 X 光工作人員配戴依院內規定配戴，定期送驗
拍攝室規定
  • 非必要人員曝光前全部退出拍攝室，關上門後再操作。
  • 懷孕員工禁止進入拍攝室，也不可接觸散射線（遠離拍攝現場）。
  • 壓制動物時，手部及身體不可進入 X 光主射束範圍，即使戴了鉛手套也一樣。
  • 操作人員站在防護屏障後方或走出房間後再曝光。
  • 盡量使用沙袋、膠帶、固定帶代替人手壓制，減少人員曝露。
⚠️
嚴格
禁止
任何人不可抱著動物一起照 X 光，即使穿著鉛衣也不可以。主射束直接穿透鉛衣，風險極高。應使用沙袋、固定帶等工具固定動物。
鉛衣保養與檢查
1
使用後直立懸掛
鉛衣使用完畢後應掛在衣架上垂直懸掛，不可折疊、堆疊或放在地板上，否則鉛層會斷裂產生破洞。
2
定期目視檢查
每月目視確認鉛衣表面有無明顯破損、縐折或不均勻。發現異常告知醫師安排 X 光驗證。

2. 動物呼吸困難時，可以直接幫牠擺 VD 位拍胸腔 X 光嗎？
不可以。VD 仰躺姿勢會使腹腔臟器壓迫肺部，加重呼吸困難，嚴重時可能危及生命。應立即告知醫師，由醫師決定是否改用 DV 位（趴臥）或先以側照代替。

3. VD 和 DV 拍攝位置有什麼差異？
VD（腹背位）：動物仰躺，X 光由腹側射向背側。DV（背腹位）：動物趴臥，X 光由背側射向腹側。DV 對呼吸困難動物較舒適，VD 心臟輪廓較對稱清楚。

4. 胸腔側照時，如何判斷動物身體沒有旋轉？
看影像中兩側肋骨是否重疊（弧度一致），若重疊代表沒有旋轉；若兩側肋骨明顯錯位（一大一小），代表動物有旋轉，擺位不夠標準。

5. 胸腔側照應在吸氣末還是呼氣末曝光？為什麼？
吸氣末曝光。此時肺部充氣最多，肺野面積最大，診斷資訊最豐富，可以更清楚評估肺葉變化。

6. 拍攝腹腔 X 光，照射範圍的前後界是哪裡？
前方需涵蓋橫膈膜（含最後肋骨），後方需到恥骨後緣（含整個膀胱）。尤其懷疑泌尿系統問題時，膀胱完整包含在範圍內非常重要。

7. 拍 X 光時，壓制動物的助理一定要穿什麼？
必須穿著鉛衣，並戴鉛手套。且手部及身體絕對不可進入 X 光主射束範圍，即使穿了防護裝備也一樣。

8. 懷孕員工可以穿鉛衣進去幫忙壓制動物嗎？
不可以。懷孕員工禁止進入拍攝室，也不應接觸散射線。鉛衣無法完全阻擋主射束，且孕期輻射容許量極低（1 mSv），應完全迴避 X 光相關工作。

9. 鉛衣使用完後，正確的收納方式是？
掛在衣架上垂直懸掛，不可折疊、堆疊或放在地板上。折疊會使鉛層斷裂產生破洞，喪失防護效果。

11. 什麼是 RL Lat 和 LL Lat？分別在什麼情況用？
RL Lat（右側臥側照）：右側朝下，為一般胸腔 / 腹腔最常用。LL Lat（左側臥側照）：左側朝下，心臟貼近板面，影像更清晰，常用於心臟評估。
